# Kordius Games

Двуязычный статический сайт независимой игровой студии. Для сборки нужен Node.js 22 или новее. На сервере работают HTML, CSS и небольшой скрипт для мобильного меню и галереи. Установки пакетов и серверной части нет.

- **Игры и общие тексты** — `site/content.mjs`. Добавьте запись в массив games, её RU/EN тексты и изображение в `site/assets/`. Сборка создаст обе страницы и добавит их в каталог и sitemap. Галерея и ссылка на политику Sticky Orbs настроены в `build.mjs`.
- **Privacy Policy** — `site/privacy.mjs`. Меняйте обе версии одновременно и обновляйте дату в `site/content.mjs`. Адреса `/privacy/sticky-orbs/` и `/ru/privacy/sticky-orbs/` сохраняйте при обновлении.
- **Контакт** — `site/content.mjs`. Адрес используется в разделе контактов и в обеих версиях политики.
- **Медиа** — три кадра из рабочих сборок Sticky Orbs. Разрешённый к публикации вывод лежит в `docs/`. Файлы игр и внутренняя матрица Data Safety не входят в репозиторий.

## Посмотреть и обновить

```powershell
node build.mjs
node preview.mjs
```

Откройте [локальный сайт](http://127.0.0.1:4173/kordius-games-site/). Подпуть совпадает с адресом сайта на Pages. Закройте предпросмотр сочетанием Ctrl+C.

GitHub Pages берёт ветку `main` и папку `/docs` через **Settings → Pages → Deploy from a branch**. Сборка добавляет `.nojekyll`. После редактирования выполните `node build.mjs`, проверьте локально, зафиксируйте изменения исходников и `docs/`, затем отправьте коммит по Git. Pages обновит сайт после push. В репозитории нет отдельного CI.

## Google Play

В **Play Console → App content → Privacy policy** укажите [прямую английскую страницу](https://kord1us.github.io/kordius-games-site/privacy/sticky-orbs/). [Русская версия](https://kord1us.github.io/kordius-games-site/ru/privacy/sticky-orbs/) доступна с того же сайта.

В Android-приложении ссылка должна быть в **Настройки → Конфиденциальность и данные → Политика игры** и открывать язык интерфейса. Заполните соответствующие RU/EN URL в Android-конфигурации при подготовке следующего кандидата. Перед отправкой проверьте ссылки и декларацию Data Safety на финальной сборке. Политика охватывает конфигурацию Sticky Orbs с выключенной коммерческой рекламой.
